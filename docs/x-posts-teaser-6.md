# LIEND X: 6 тизеров функционала

Голос как в `docs/x-posts-45.md`. Факты только из сайта, расширения и App. Токена нет. CA нет.

Не повторяем занятые кадры: слоган, SELL-карточки, ACCESS GATE, `ct is loud`, triptych, полная панель CONNECT, PAIRING APPROVE, POSITIONS-стол, FAQ, hero-небо, how-it-works рельс, quote REVIEW ROUTE, LOANS, LIVE-tape с бегущими строками, пустые слоты цены, REVOKE, манифест.

Порядок в ленте: 1 → 2 → 3 → 4. Посты 5 и 6 — паузы.

## Пост 1

**Почему**

Реальный вход расширения. Не «мы на каждом терминале». Кнопка сама, жест сам, host не перекрашиваем.

**Пост**

```
CHECK LIQUIDITY

lower left on pump.fun
away from the buy box
it doesn't restyle the host

the panel only opens if you click it
```

**Промпт к картинке**

16:9 cropped lower-left of a dim pump.fun token page. One small LIEND glass control, Silkscreen `LIEND · Check liquidity`, nested pixel teardrop 12px. Host buy/sell stack stays far right, out of focus, not restyled. No side panel open, no price overlay, no CONNECT, no Chrome store tile. Apply the LIEND webcore lock from Visual bible.

**Почему картинка**

Только триггер. Полную панель и CONNECT уже снимали.

## Пост 2

**Почему**

Handoff с pump.fun в App. Панель не тащит цену и баланс. App заново читает позицию.

**Пост**

```
OPEN IN LIEND

the panel hands the mint
and that it came from pump.fun
that's the whole payload

the app fetches the position itself
```

**Промпт к картинке**

16:9 split. Left: LIEND sidepanel chrome, titlebar LIEND, one shortened mint in IBM Plex Mono, source `pump.fun`, primary control `Open in LIEND`. Right: App address bar only `/positions/…?src=pumpfun`, same mint, no balances, no quote numbers. Nested pixel teardrop 16px on both titlebars. No pairing code, no empty price slots as the hero. Apply the LIEND webcore lock from Visual bible.

**Почему картинка**

Минт едет, цифры нет. Панель без цены уже была отдельным постом.

## Пост 4

**Почему**

Сам borrow в App: ты называешь SOL, max уже от позиции, terms на следующем экране. Не CTA Review route.

**Пост**

```
BORROW AMOUNT

you type the SOL
max sits under the field from that position

collateral
you receive
fee
ltv

confirm is one screen later
```

**Промпт к картинке**

16:9 App window, titlebar BORROW, one muted ticker → SOL in the subtitle. Hero is the Borrow amount field with Max hint under it in Plex Mono. Quote rows sit quieter below: Collateral, You receive, Fee, LTV. No Review borrow button filling the frame, no Confirm borrow, no unsigned stamp. Nested pixel teardrop 16px. Apply the LIEND webcore lock from Visual bible.

**Почему картинка**

Поле суммы. Quote-CTA и unsigned stamp уже заняты.

## Пост 5

**Почему**

Калькулятор на сайте до кошелька. Illustrative, не live quote. Health state есть, live params могут быть другими.

**Пост**

```
PUBLIC CALCULATOR

model the position before connecting
token value
collateral
borrow

it prints estimated SOL and a health state
live params can still differ
```

**Промпт к картинке**

16:9 landing window, titlebar LIQUIDITY LAB. Left: Token value, Collateral slider, Borrow slider. Center route chips POSITION → COLLATERAL → SOL. Right: ESTIMATED OUTPUT, Estimated SOL in Plex Mono, Health State pill. One small footer line that live conditions can differ. No wallet connect, no ACCESS GATE, no meadow hero. Nested pixel teardrop 16px. Apply the LIEND webcore lock from Visual bible.

**Почему картинка**

Лаб, не configure/LTV риск-экран и не quote в App.

## Пост 6

**Почему**

Честная лента. Когда маршрутов нет, она так и пишет. Не рисуем тик.

**Пост**

```
listening for routes

that's the tape when nothing's moving
no fake borrow
no fake repay
```

**Промпт к картинке**

16:9 extreme crop of the navy LIVE tape only. Green LIVE pill on the left, one idle Silkscreen string `listening for routes`, empty track, no BORROW / REPAY / SWAP chips scrolling. Nested pixel teardrop tiny in the LIVE block. No Solscan modal, no dashboard cards, no single activity row with a signature. Apply the LIEND webcore lock from Visual bible.

**Почему картинка**

Idle-строка. Бегущую ленту и одну подпись уже снимали.
