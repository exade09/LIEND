# LIEND X: посты

22 до лаунча, 10 после. Голос с [JOMO](https://x.com/jomoagent) и [Utopia Agent](https://x.com/UtopiaAgent). Факты только из продукта.

С 4-го вырезаны повторы: слоган, SELL-карточки, ACCESS GATE, «ct is loud», три окна, side panel, FAQ, hero-небо. Каждый пост бьёт в один факт и в один кадр.

Перед лаунчем **не вставляй CA**. После лаунча замени:

- `[CA]` — реальный mint
- `[PUMP_URL]` — официальная страница монеты на pump.fun
- `liend.app` — тот origin, который реально в шапке

---

## Что делают эти два аккаунта

### JOMO (@jomoagent)

Lowercase, рубленые строки, почти без эмодзи и хештегов. Продукт раньше токена.

1. Pinned launch: `$ jomo is live` / `ct is loud` / `this is the part that stays quiet` / `ca:` / `enter:`
2. Честность до CA: `website is live. token isn't. for now.`
3. CAPS-лейбл фичи + вопрос без знака вопроса
4. Сухой абзац что это за продукт (extension + web app)
5. How-to со стрелкой и скрином

### Utopia Agent (@UtopiaAgent)

1. Слой между A и B, потом `ENTER`
2. Feature drop `you can now` без выдуманных фич
3. Proof, не обещание (у них Streamflow, у нас explorer)
4. Философия без продукта в каждой строке

Не берём их CA, rewards, telegram-алерты, фейковый lock, снайпер-коуч.

Слоган сайта живёт только в посте 1. `ct is loud` живёт только в launch-pin.
